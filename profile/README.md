# Q4H2O Research Collective

A multi-institution research collective applying quantum computing to water-resource problems, sponsored by [Q4H2O](https://q4h2o.com).

## Repositories

- [vqmar-georgia01](https://github.com/q4h2o-research-collective/vqmar-georgia01) – Variational quantum-classical hybrid framework for Managed Aquifer Recharge site selection. Companion code for the IEEE QCE 2026 QECS paper.
